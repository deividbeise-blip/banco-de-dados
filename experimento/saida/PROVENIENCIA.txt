PROVENIENCIA DAS RESPOSTAS DO LLM

ORIGEM
  As 10 respostas em saida/manual (controle_01..05 e defeitos_01..05) foram geradas
  em 14/11/2026 com o modelo Claude Opus 5.5, pelo Claude Code em modo nao interativo
  (claude -p --model opus), pelo script rodar_claude_code.ps1.

ISOLAMENTO
  - Cada chamada roda em uma pasta vazia fora do repositorio (C:\temp\llm-isolado).
  - Ferramentas desabilitadas: Read, Bash (e PowerShell), Glob, Grep, Edit, Write,
    NotebookEdit, WebFetch, WebSearch, Task.
  - O modelo recebe apenas o prompt (saida/prompt_controle.txt ou
    saida/prompt_defeitos.txt) pela entrada padrao, sem acesso ao gabarito,
    aos scripts ou as bases.
  - Cada chamada e uma sessao nova, sem memoria das anteriores.
  - A temperatura nao e configuravel nessa interface.

CONVERSAO
  importar_manual.py converte cada resposta em saida/respostas/<base>_execNN.json,
  com modelo, interface, data, hash do prompt e o texto original (resposta_bruta).
  Se a resposta nao passar na validacao de formato, o importador remove aspas,
  crases, asteriscos, espacos e ponto final das bordas e confere se sobrou
  exatamente "nenhum problema encontrado". Caso observado em controle_02
  ("nenhum problema encontrado" entre aspas), registrado no JSON como
  "normalizado": true. Respostas com JSON nunca sao alteradas.

HISTORICO
  Uma primeira rodada foi feita no chat do claude.ai, mas parte das respostas se
  perdeu e foi reconstruida, e havia conversas com outro modelo (Sonnet 4.6).
  Por isso todas as execucoes foram refeitas no Claude Code. As respostas
  dessa primeira rodada estao no commit db1f2fd e nao entram nas metricas.
